03 三步进服

从喜欢的地方
开始。

不需要整合包，不需要额外程序。用官方客户端，填上地址就能进来。

  1. 1

    打开官方客户端

    Java 版 1.21 及以上或基岩版都可以；Java 用官方启动器，基岩版用游戏内服务器列表。

  2. 2

    添加服务器

    Java 在“多人游戏”里添加，基岩在“服务器”里添加，地址都填 pepper.ltd。服务器强制正版验证。

  3. 3

    进世界，慢慢来

    输入 /pej 去主世界，找块喜欢的地方，用 /sethome 设家。

04 你可能想问

进来之前，
先把疑问放下。

还有问题？

加群问一句，通常很快有人回答。

服务器收费吗？

完全免费的公益服：没有充值特权，没有氪金项目。

存档会被清除吗？

不会。2025 年 1 月服务器郑重决定：3 年内不再清除存档内容。

可以用钻石当货币交易吗？

可以，钻石就是通用货币。建议用 /bank add <数量> 存入银行，用 /pay 转账，避免丢失。

如何保护我的建筑？

手持普通金锄，左键点第一个角、右键点对角，再输入 /pclaim create <名字> 圈出个人领地；加入或创建联盟（/union）后，还能用 /gclaim create <名字> 圈联盟公共领地。

服务器卡吗？允许高频红石吗？

高性能硬件与优化配置，同时有反作弊保障公平。允许高频红石、刷铁机；大型红石与高频操作请控制规模。禁止利用漏洞复制物品或刷取经济，发现漏洞请报告管理组。

基岩版怎么进？

在游戏的“服务器”里添加 pepper.ltd；进服后 Java 玩家会看到你的名字带 BE- 前缀，可以用 /pclaim gui、/homes 等图形界面。
